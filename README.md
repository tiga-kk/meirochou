# ComiPath Web

ComiPathのローカル公開候補リポジトリです。
本リポジトリは、コミケ会場でのスマホ片手操作を支援する地図表示・経路案内アプリを提供します。

## サポートマトリクス

| 機能 | サポート状況 | 備考 |
|---|---|---|
| 地図 / ナビゲーション | あり | デモマップ (`demo-v1`) によるピン表示・経路探索 |
| CSV サービス API | あり | `DataManager` によるローカルCSVインポート・エクスポート・置換 |
| 管理 UI | なし | UIからの設定操作は未実装 |
| GAS 同期 | なし（GAS同期は未実装） | Phase 3 にて実装予定 |

## 機能概要

- **地図ピン**: 選択したサークルのスペース位置を地図上にピン表示します。
- **経路変更**: 巡回順序に応じた経路候補を生成し、現地での動的な経路変更を可能にします。
- **現在の経路と候補経路**: 現在の移動経路と、目的地を変更した場合の候補経路を視覚的に比較できます。
- **部分的なオフライン対応 (LocalStorage)**: アプリ読み込み後、巡回リストや購入状態等のローカルデータは `LocalStorage` を利用して端末内に保存されます（単一端末内での動作に限られ、他端末との自動同期はありません）。

## データ契約とCSV仕様

詳細なデータ構造や TypeScript API 仕様については [データ契約ドキュメント](docs/data-contracts.md) を参照してください。

巡回リストの CSV および内部データ構造は以下の列（ヘッダー）で構成されます：

- `space`: スペース番号 (必須)
- `priority`: 優先度
- `isSale`: 購入済みステータス（購入時は `x` をセット）
- `account`: アカウント情報
- `tweet`: お品書きなどのツイート/画像情報
- `memo`: メモ欄

ヘッダー順序は `space,priority,isSale,account,tweet,memo` となります。

## 開発・検証手順

本プロジェクトの開発・検証には以下のコマンドを使用します：

```bash
# 依存関係のクリーンインストール
npm ci

# 開発用ローカルサーバーの起動
npm run dev:webapp

# テストおよび検証スクリプトの実行 (Vitest / 静的解析 / ビルド)
npm run verify

# コードフォーマット・Linter検証
npx biome check

# PlaywrightによるE2Eテストの実行
npm run test:e2e

# 改行コード・末尾空白の検証
git diff --check
```

## 環境設定

通常の開発では、付属する fictional な `demo-v1` マップが使用されます。公開候補には実地図・private mapを含めません。
