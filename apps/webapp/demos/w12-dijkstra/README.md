# W12 Dijkstra Visualizer

C108のW12地図上で、クリック地点からの重み付きダイクストラ距離をアニメーション表示する発表用ページです。

## 起動

リポジトリルートで次を実行します。

```bash
npm ci
npm run dev:webapp
```

ブラウザで次を開きます。

```text
http://127.0.0.1:5173/demos/w12-dijkstra/
```

W12の `map.svg`、`grid-meta.json`、`grid.bin` は、既存のC108マップバンドルから自動で読み込みます。

## 操作

- 地図上をクリックすると、その地点を始点として計算します。
- 障害物をクリックした場合は、最寄りの通行可能セルへ自動補正します。
- 再生時間は0.9秒、1.8秒、3.5秒、6.0秒、10秒、20秒、30秒から選べます。
- 地図倍率は100%から300%まで25%刻みで変更できます。
- 拡大した地図は表示枠内をスクロールして移動します。
- 再生中は一時停止・再開できます。
- 「表示を消す」でヒートマップを消去します。
