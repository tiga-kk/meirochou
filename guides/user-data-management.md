# ComiPath データ管理ガイド

ComiPath のローカルデータ管理機能の使い方を説明します。設定画面（⚙️ ボタン）から各機能にアクセスできます。

## 1. イベント・日程の選択と切り替え

設定画面の上部にある「**イベント**」「**日程**」セレクタで、閲覧・管理するデータを切り替えます。

- セレクタを変更すると、地図とサークルデータがその日程のものに切り替わります。
- 切り替えの途中に失敗した場合、以前の日程と地図の状態に戻ります。
- 「(未設定)」と表示されている日程は、まだCSVやGASソースを設定していない状態です。
- 「\[送信待ち:N件\]」は、その日程に未送信のGAS同期が残っていることを示します。

## 2. CSVファイルのインポートと差し替え

**CSVファイルタブ**でローカルのCSVファイルからサークルデータをインポートします。

### 初回インポート

1. 設定画面を開き、「**CSVファイル**」タブを選択します。
2. ファイル選択ボタンで `.csv` ファイル（5MB以下）を選択します。
3. 変更内容のプレビュー（追加・更新・削除の件数）が表示されます。
4. 内容を確認して「**変更を適用**」を押すと、ローカルに保存されます。

### CSVの差し替え

同じ手順で新しいCSVを選択すると、既存データとの差分がプレビューで表示されます。ローカルの購入状況・保留リスト・操作履歴は維持されます。

### CSVファイルの書式

必須列: `space`（スペース番号）。任意列: `priority`（優先度）、`isSale`（頒布状況）、`account`（Xアカウント等）、`tweet`（ツイートURL等）、`memo`（メモ）。

> **注意**: `=`, `+`, `-`, `@` で始まる値は数式に見える文字列として保持されますが、ComiPath内では実行されません。エクスポートしたCSVをスプレッドシートソフトで開く場合は、外部ソースとして扱ってください。

## 3. Googleスプレッドシート（GAS）の設定と同期

ComiPath はオプションで Google Apps Script（GAS）を使ったスプレッドシート連携に対応しています。

### GASのデプロイ

1. `npm run build:gas` を実行して `Code.gs` を生成します。
2. Google スプレッドシートの「拡張機能」→「Apps Script」を開きます。
3. `Code.gs` の内容を貼り付け、「デプロイ」→「新しいデプロイ」でWebアプリとして公開します。
4. デプロイ後のURLを控えておきます（`https://script.google.com/macros/s/.../exec` の形式）。

### シートの選択と初回インポート

1. 設定画面で「**Googleスプレッドシート**」タブを選択します。
2. デプロイしたWebApp URLを入力し、「**シート一覧を取得**」を押します。
3. シートを選択し、「**プレビューを表示**」を押します。
4. 差分を確認して「**変更を適用**」を押します。

### GASソースの差し替え・明示的な更新（refresh）

同じシートを選択してプレビューを取得すると「**更新（refresh）**」モードになります。別のシートや別のURLを選ぶと「**差し替え**」モードです。いずれもプレビュー確認後に適用します。

> **注意**: デプロイURL全体はユーザーのブラウザのLocalStorageに保存されます。このリポジトリは公開エンドポイントやスプレッドシートIDを含みません。

## 4. 購入・保留の操作と送信待ち件数

- 地図上のサークルピンまたはボトムシートで「**購入**」「**保留**」「**キャンセル**」を選択します。
- 操作はまずLocalStorageに即時保存されます。GASソースを使っている場合は、購入・取消が「送信待ち（gasOutbox）」に追加されます。
- 送信待ち件数はセレクタの `[送信待ち:N件]` や「GAS同期 キュー管理」パネルで確認できます。
- 保留（キープ）はGAS側には送信されません。LocalStorageのみに記録されます。

## 5. GAS同期の再送と破棄

「**GAS同期 キュー管理**」パネルで送信待ちエントリを管理できます。

### 再送（retry）

- 「**すべて再送**」または日程ごとの「**再送**」ボタンで再試行します。
- ブラウザがオンラインになったとき、アプリ起動時にも自動で再送が試みられます。
- 失敗したエントリはカテゴリのみ表示され、詳細なエラー内容はUIに表示されません。

### 破棄（discard）

エントリにチェックを入れて「**選択したN件を破棄**」を押すと確認ダイアログが表示されます。

- 確認欄に `未送信を破棄` と入力して実行します。
- 破棄は**未送信のGASへの通知のみ**を削除します。**端末のLocalStorageにある購入状況は変わりません**。
- 破棄後、GAS側のスプレッドシートと端末の購入状況が一致しない場合があります。

> **注意**: 破棄は取り消せません。誤って破棄した場合は、手動で購入操作をやり直す必要があります。

## 6. データの削除

「**ローカルデータ管理**」セクションには4種類の削除オプションがあります。送信待ちのGAS同期が残っている場合、関連するオプションはロックされます。

### 1. サークルリストの削除

現在の日程のサークルリスト（CSV/GASから取得したデータ）を削除し、空のリストにします。ローカルの購入状況・操作履歴は残ります。

### 2. 活動・履歴の削除（履歴のみ）

現在の日程の購入・保留・操作履歴を削除します。サークルリストは残ります。

### 3. 日程データの削除

現在の日程のサークルリスト・購入状況・履歴・ソース設定をすべて削除します。日程インデックスから除外されます。

### 4. 全イベントの削除

登録されているすべてのイベント・日程データを削除します。確認欄に `全イベントを削除` と正確に入力して実行します。この操作は元に戻せません。

## 7. CSVエクスポート

ソース管理パネルの「**CSVエクスポート**」ボタンで、現在の日程データをCSVファイルとしてダウンロードできます。

- エクスポートは読み取り専用です。ソースの世代番号・購入状況・履歴・outboxは変わりません。
- ファイル名はダウンロード日時を含む形式です。
- `removedFromSource` フラグが付いた行（ソースから削除済みの行）はエクスポートに含まれません。
- 購入状況は現在のLocalStorageが正本として使われます。

## 8. 端末・データの制限事項

- ComiPath のデータは**ブラウザの LocalStorage**に保存されます。
- **単一端末**（1台のブラウザ）のみが正本です。複数デバイス間のマルチデバイス同期やJSONバックアップはサポートしていません。
- ブラウザのデータ消去、プライベートブラウジング終了、またはLocalStorageの容量超過により、データが失われる場合があります。

## 9. エラーと安全な回復

### ストレージエラー

保存操作が失敗した場合、ユーザーに操作が成功しなかったことが通知されます。LocalStorageの状態は変更されません。

### GAS ネットワークエラー

GAS POSTが失敗しても、LocalStorageの購入状況は変わりません。エントリは送信待ちのまま残り、後で再送できます。

### プレビューの期限切れ

プレビューが古い場合（日程切替やソース変更後など）、適用時にエラーが表示されます。再度プレビューを取得して適用してください。

### 無効なソースエラー

CSVの形式が正しくない場合や、GASのURLが無効な場合は、プレビュー前または適用前にエラーが表示されます。データは変更されません。
